Erdős #982 — distances distinctes vues depuis un sommet d’un polygone convexe

Aucun contre-exemple n’existe pour n ≤ 13 (vérification exhaustive machine, sous réserve des deux derniers jobs en cours) ; toutes les familles structurées connues et leurs voisinages entiers sont exclus par des théorèmes ; le mécanisme central découvert — le comptage de classes bat la rigidité — réduit la mort d’une famille à un inventaire de racines élémentaire.

Soit P ⊂ ℝ², |P| = n ≥ 3, en position convexe stricte ; pour x ∈ P on pose D(x) = |{ |xy| : y ∈ P privé de x }| et M(P) = max_x D(x). Conjecture d’Erdős (1946) : M(P) ≥ ⌊n/2⌋ — le quantificateur est ∃x, pas ∀x. La borne est serrée (le n-gone régulier donne D ≡ ⌊n/2⌋), et un contre-exemple est donc un n-gone convexe dont TOUT sommet voit ≤ K = ⌊n/2⌋ − 1 distances distinctes. Statut externe : ouvert ; Altman (1963) donne la version faible (nombre TOTAL de distances ≥ ⌊n/2⌋) et le record per-vertex est (13/36 + ε)n − O(1) avec ε ≈ 1/23000 (Nivasch–Pach–Pinchasi–Zerbib, arXiv:1207.1266), soit ≈ 0,361n contre 0,5n.
